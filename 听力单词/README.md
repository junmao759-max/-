# 考研英语听力单词 · 每日生成系统

> 每天自动生成 **40 个不重复**的考研英语听力高频词（`md` 学习文件 + `txt` 听写清单），已用单词自动去重，永远不会重复。

---

## 📁 目录结构

| 文件 | 说明 |
|---|---|
| `YYYY-MM-DD-考研听力单词.md` | 每日学习文件：音标 / 词性 / 释义 / 例句 / 译文 / 听写清单 |
| `YYYY-MM-DD-听写单词.txt` | 每日纯单词列表（一行一词），用于导入听写网站 |
| `bank_part*.tsv` | 词库（A–I 九大主题，1520 个唯一词），可继续扩充 |
| `used_log.csv` | 已用词表（word,date），保证全库去重 |
| `index.md` | 总索引，汇总每天的文件链接 |
| `generate_daily.ps1` | 每日生成脚本 |
| `validate_bank.ps1` | 词库校验工具（检查格式/重复/异常行，`-Fix` 参数自动清洗） |

## 🚀 每天怎么用

打开 PowerShell（当前目录为 `听力单词` 文件夹），运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\generate_daily.ps1
```

- 默认生成**当天日期**的 40 个词（不重复、随机抽取）。
- 指定日期补生成：`-Date 2026-09-02`
- 指定数量：`-Count 40`
- **已生成的日期会自动跳过**（防止重复生成）；已用过的单词也会自动排除。

## 🔒 去重机制

1. 每次生成只从 `bank_part*.tsv` 中**未被使用过**的词里随机抽取 40 个；
2. 用过的词写入 `used_log.csv`（word + 日期），跨天、跨月都不会重复；
3. 脚本检测到当天 md 已存在时直接退出，不会覆盖或重复生成。

## 📝 扩充词库（可选）

词库不足 40 词时会警告。新增任意 `bank_partG.tsv` 等文件即可扩充，每行格式（竖线分隔 7 个字段）：

```
word|phonetic|pos|meaning|example|translation|topic
```

示例：`abandon|əˈbændən|v.|放弃；抛弃|They had to abandon the plan.|他们不得不放弃这个计划。|校园与学习`

## 🎧 听写网站推荐（支持导入文件）

### ⭐ 首选：直接导入文件听写

1. **Quizlet**（[quizlet.com](https://quizlet.com)）— 免费
   - 新建学习集 →「导入」→ 粘贴/上传每日 `听写单词.txt`（一行一词即可）；
   - 自带美式/英式 **TTS 朗读**，用「**拼写模式**（Spelling）」练习：听发音→打字拼写，就是最标准的单词听写；
   - 手机 App 与网页同步，最适合每天 40 词快速过一遍。

2. **Listen and Write**（[listen-and-write.com](https://www.listen-and-write.com)）— 免费
   - 专为听写而生：支持**上传音频文件**或粘贴 YouTube 链接，自动生成逐句听写练习；
   - 先隐藏字幕盲听打字，再看答案，可调速、可重复播放；
   - 配合「把每日单词用 TTS 转成 mp3」即可实现自己词表的整句/单词听写。

3. **每日英语听力**（欧路旗下，App + 网页 [dict.eudic.net](https://dict.eudic.net)）— 免费
   - 素材库海量（真题、新闻、影视、公开课），有「**精听模式**」：逐句播放→打字→自动判分；
   - 支持**导入本地音频/文本**（添加自己的听力材料），适合把单词例句音频放进去精听。

4. **VoScreen**（[voscreen.com](https://www.voscreen.com)）— 免费/会员
   - 用真实视频片段练听力理解，可**上传自己的视频/音频**生成精听、跟读练习；
   - 选项式的听辨训练，趣味性强，适合碎片时间。

### 📚 现成任务 / 资源（不用自己准备材料）

5. **沪江听写酷**（[ting.hujiang.com](https://ting.hujiang.com)）— 老牌听写社区
   - 有考研、四六级、新闻等大量**现成听写任务**，逐句听写+社区互评；
   - 也可以把自己的音频做成听写节目（需上传音频）。

6. **可可英语**（[kekenet.com](https://www.kekenet.com)）／**在线英语听力室**（[tingroom.com](https://www.tingroom.com)）
   - 大量考研复试听力、VOA/CNN、真题听力原文与逐句听写资源，适合做泛听+精听补充。

### 📱 手机 App 补充

7. **墨墨背单词 / 万词王** — 都支持**自定义词书导入**（txt/csv），墨墨有「听音辨义」，万词王有听写训练，通勤时用。

### 🛠️ 开源小工具

8. **TypeWords**（[github.com/CelPlume/TypeWords](https://github.com/CelPlume/TypeWords)）— 开源、免费、无需注册的拼写背单词网站，靠打字拼写巩固，可当听写替代（支持导入词表）。

### 💡 推荐每日工作流

```
早上：读当日 md（音标+例句）→ 熟悉 40 词
晚上：把 听写单词.txt 导入 Quizlet → 拼写模式听写一遍
进阶：用 Edge 浏览器「大声朗读」把例句转成音频 → 导入 Listen and Write / 每日英语听力 做整句听写
```

## ⚠️ 小提示

- 考研英语**初试不考听力**，听力主要出现在**复试**（各校口语/听力测试）；本词库覆盖考研大纲核心高频词 + 听力场景词，同样适用于四六级听力备考。
- 音标、例句由 AI 生成，若发现个别音标偏差，可直接修改当日 md 文件，或修正词库后（该词会进入已用表，不会重复出现）。
