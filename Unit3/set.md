### set｜一组 / 电视机 / 安排好的
**① 一组、一套、集合（名词 a set of）**
> "Thus, the anthropological concept of 'culture,' like the concept of 'set' in mathematics, is an abstract concept which makes possible immense amounts of concrete research and understanding."
> 出处：2003年 英语（一）翻译真题（第64题）
> 译文：因此，人类学中"文化"这一概念，就像数学中"集合"这一概念一样，是一个抽象概念，它使大量具体的研究和认识成为可能。
> ?? 此句中 set 即"集合、组"这一名词义；常用搭配 a set of rules 一套规则、a set of tools 一套工具。

**② 电视机（a television/TV set 中的"装置"义）**
> ??【自行生成例句】未检索到该义项的考研真题原句，以下为自行编写，仅供理解记忆：
> "The old couple still watches the news on a black-and-white TV set."
> 译文：这对老夫妇仍用一台黑白电视机收看新闻。
> ?? 该义为"装置、设备"：a radio/TV set 收音机/电视机；set 名词还可指电影、戏剧的"布景"。

**③ 安排好的、固定的、准备好的（形容词）**
> ??【自行生成例句】未检索到该义项的考研真题原句，以下为自行编写，仅供理解记忆：
> "The lecture will start at a set time, so please arrive ten minutes earlier."
> 译文：讲座将在规定（事先安排好的）时间开始，请提前十分钟到场。
> ?? set 形容词：固定的、事先安排好的（a set phrase 固定搭配、at a set time 在规定时间）；下定决心的（be set on doing sth 决心做某事）；即将、准备好（be set to do sth）。真题中 set 动词短语考查极多：set out 出发；着手；set up 建立；set off 出发；引爆；set about doing 着手做。
